# Engineering Experimental Class Co-creation Space

**工科试验班（人工智能类）2501 · 共创空间**

湖南大学人工智能与机器人学院首届工科试验班的班级工作台：用 AI 协同班务、学业与科研竞赛，开源可核验。

仓库：<https://github.com/AntonyTang-AT/Engineering-Experimental-Class-Co-creation-Space>  
线上：<http://1.14.46.251/>（学号登录，密码为学号后六位）

## 这是什么

不是通用刷题站，而是 **2501 班自己的共创空间**：

- **班务共创**：作业清单、留言墙、共享资料认领
- **学业共创**：高数 / 大物 / 计概计划、练习、资料与提醒
- **科研与竞赛**：课题进度、竞赛节点、论文专利与组队公开板
- **真实花名册**：20 名同学，账号即学号

班级关键词：**敢为人先 · 全员进组 · AI 赋能班集体**

## 本地启动（简版）

```bash
# 后端
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m scripts.seed_demo_accounts
uvicorn app.main:app --reload --port 8000

# Agent（另开终端）
cd agent
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001

# 前端
cd frontend
npm install
npm run dev
```

环境变量参考 `backend/.env.example`、`agent/.env.example`（含 DeepSeek 等，勿把密钥提交进仓库）。

## 技术栈（摘要）

前端 React + Vite + Ant Design；业务后端 FastAPI + SQLite；智能内核独立 `agent/` 服务（多智能体协商 + LLM）。  
班级公共内容与花名册仅展示**姓名**等可公开信息，不入库电话/寝室。
